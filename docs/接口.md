# Spark 接口文档

> 本文档是 Spark HTTP API 的**唯一契约**，由 `apps/web/src/app/api/**/route.ts` 实际生成。
> 任何对路由、参数、响应、错误码的修改必须同 PR 提交并在此更新。

## 一、通用约定

### 1.1 基础信息

| 项 | 取值 |
|----|------|
| Base URL | `http://localhost:3000`（开发）/ 生产环境域名 |
| 协议 | HTTP/1.1、HTTP/2 |
| 数据格式 | JSON（`Content-Type: application/json`） |
| 字符集 | UTF-8 |
| 鉴权 | V1 单机单用户，**无鉴权**；V2 起需接入 |

### 1.2 时间格式

- 输入：`ISO 8601`（`2026-08-21T10:00:00Z`）或 MySQL 接受的 `YYYY-MM-DD HH:mm:ss.SSS`
- 输出：`DATETIME(3)` 直接以 ISO 字符串返回
- 所有时间戳**带毫秒**

### 1.3 错误响应

所有错误均以 JSON 返回，结构：

```json
{ "error": "错误描述（中文）" }
```

| 状态码 | 语义 | 出现场景 |
|--------|------|---------|
| 200 | 成功 | 正常 GET / PUT |
| 201 | 已创建 | POST 创建成功 |
| 400 | 请求参数错误 | 缺字段、字段格式错误 |
| 404 | 资源不存在 | idea_id 不存在 |
| 405 | 方法不被允许 | 路由不支持该动词 |
| 409 | 资源冲突 | 关联已存在 |
| 500 | 服务器内部错误 | DB 异常、AI 调用异常未捕获 |

### 1.4 分页

| 参数 | 默认 | 范围 |
|------|------|------|
| `page` | 1 | ≥1 |
| `pageSize` | 20 | 1-100 |

返回体统一为 `{ data, total, page, pageSize }`，部分接口省略 `total`。

### 1.5 排序参数

| 值 | 含义 |
|----|------|
| `important` | 默认，按 importance DESC, created_at DESC |
| `newest` | 按 created_at DESC |
| `oldest` | 按 created_at ASC |
| `updated` | 按 updated_at DESC |
| `status` | 按状态机顺序：seed→sprout→growing→realized→archived→dormant |


## 二、想法 CRUD

### 2.1 `GET /api/ideas`

列出想法（带筛选、搜索、分页）。

**Query 参数**

| 参数 | 类型 | 必填 | 含义 |
|------|------|------|------|
| `q` | string | 否 | 模糊匹配 title/content |
| `collection` | string | 否 | 按集合精确匹配 |
| `status` | string | 否 | 逗号分隔多值，如 `seed,sprout` |
| `importance` | string | 否 | 逗号分隔多值，如 `3,4` |
| `parent` | string (UUID) | 否 | 列出 parent_a_id 或 parent_b_id 等于该值的所有杂交子 |
| `backlinks` | string (UUID) | 否 | 列出"内容中包含 `[[该想法的标题]]`"的所有想法（双向链接） |
| `sort` | string | 否 | 见 §1.5，默认 `important` |
| `page` | int | 否 | 默认 1 |
| `pageSize` | int | 否 | 默认 20 |

**响应**

```json
{
  "ideas": [Idea, ...],
  "total": 123,
  "page": 1,
  "pageSize": 20
}
```

### 2.2 `POST /api/ideas`

创建想法（闪电捕获）。

**请求体**

```json
{
  "title": "string（必填，≤500 字）",
  "content": "string（可选，Markdown）",
  "collection": "string（可选）",
  "importance": 0,
  "is_capsule": false,
  "unlock_at": "2026-12-01T00:00:00Z",
  "parent_a_id": "uuid（可选，杂交时填）",
  "parent_b_id": "uuid（可选，杂交时填）",
  "emotion": "excited"
}
```

**响应**：`201 Created` + 完整 `Idea` 对象。

**副作用**：

- 自动写 `idea_activities(type=capture)`
- 若 `parent_a_id && parent_b_id`，再写一条 `idea_activities(type=general)` 记录杂交诞生

**错误**：`400 标题不能为空`

### 2.3 `GET /api/ideas/:id`

获取单个想法详情。

**响应**：`200` + `Idea`；`404 想法不存在`。

### 2.4 `PATCH /api/ideas/:id`

更新想法。所有字段可选；只传 `body` 中出现的字段会被写入。

**可更新字段**：`title` / `content` / `status` / `importance` / `collection` / `last_reviewed_at` / `is_capsule` / `unlock_at` / `epitaph` / `emotion`

**响应**：`200` + 更新后的 `Idea`。

**副作用（自动活动日志）**：

- `status` 变化 → `status_change`
- `importance` 变化 → `importance_change`
- `epitaph` 写入 → `general`（"墓志铭：xxx"）
- `emotion` 写入 → `emotion`

### 2.5 `DELETE /api/ideas/:id`

删除想法（级联删除 `idea_activities`）。

**响应**：`204 No Content`。

## 三、想法活动（Idea Activity）

### 3.1 `GET /api/ideas/:id/activities`

列出活动的活动列表，按 `created_at DESC`。

**响应**：

```json
[{ "id": "...", "idea_id": "...", "type": "capture", "content": "...", "created_at": "..." }]
```

### 3.2 `POST /api/ideas/:id/activities`

用户手动追加一条活动。

**请求体**：`{ "type": "general", "content": "..." }`

**响应**：`201` + 新增的 `Activity`。

**错误**：`400 活动内容不能为空`。

## 四、想法分析存档（Idea Analysis）

### 4.1 `GET /api/ideas/:id/analyses`

获取某想法的所有分析存档，按 `created_at DESC`，最多 50 条。

**响应**：

```json
{
  "analyses": [
    {
      "id": "uuid",
      "idea_id": "uuid",
      "dimensions": [{ "name": "...", "content": "..." }, ...],
      "model": "deepseek-v4-flash",
      "tokens_used": 1234,
      "created_at": "..."
    }
  ]
}
```

### 4.2 `POST /api/ideas/:id/analyses`

用户在前端确认后保存一份分析（`/api/ai/analyze` 只生成不存）。

**请求体**：

```json
{
  "dimensions": [{ "name": "string", "content": "string" }, ...],
  "model": "string",
  "tokens_used": 1234
}
```

**校验**：`dimensions` 必须为非空数组，每项含 `name` 与 `content`。

**响应**：`200` + 新增的存档。

**错误**：`400 维度格式错误` / `404 想法不存在`。

### 4.3 `PATCH /api/ideas/:id/analyses/:analysisId`

更新一条已存档的分析（多用于用户补充或修改追问回答，`answer` 随 `dimensions` 一起更新）。

**请求体**：

```json
{ "dimensions": [{ "name": "string", "content": "string" }, ...] }
```

**校验**：`dimensions` 必须通过 `validateDimensions`。

**响应**：`200 { "ok": true }`。

**错误**：`400 维度格式错误` / `404 分析记录不存在`（含 idea_id 不匹配）。


## 五、想法关联（Idea Relationship）

### 5.1 `GET /api/relationships`

列出关联。

**Query 参数**

| 参数 | 类型 | 含义 |
|------|------|------|
| `idea_id` | UUID | 限定 source 或 target 为该想法 |
| 无参 | - | 返回最近 100 条 |

**响应**：

```json
{
  "relationships": [
    {
      "id": "uuid",
      "source_id": "uuid",
      "target_id": "uuid",
      "type": "related",
      "created_by": "user",
      "ai_explanation": "string | null",
      "created_at": "..."
    }
  ]
}
```

### 5.2 `POST /api/relationships`

创建关联。

**请求体**：

```json
{
  "source_id": "uuid",
  "target_id": "uuid",
  "type": "related",
  "created_by": "user",
  "ai_explanation": "可选，AI 推荐时附带"
}
```

**约束**：

- `source_id !== target_id`
- 双向去重：`(A,B)` 或 `(B,A)` 已存在则拒绝

**错误**：`400 无效的关联` / `409 关联已存在`。

### 5.3 `DELETE /api/relationships/:id`

删除一条关联。

**响应**：`204 No Content`。

## 六、集合（Collection）

### 6.1 `GET /api/collections`

列出所有集合及其包含的想法数量。

**响应**：

```json
[{ "name": "产品灵感", "count": 12 }, { "name": "技术笔记", "count": 8 }]
```

### 6.2 `PUT /api/collections`

重命名集合。

**请求体**：`{ "oldName": "...", "newName": "..." }`

**响应**：`{ "success": true }`。

**错误**：`400 集合名不能为空`。

### 6.3 `DELETE /api/collections`

将指定集合下所有想法的 `collection` 置空（解散集合）。通过 query 参数指定集合名。

**响应**：`{ "success": true }`。

**错误**：`400 缺少集合名`。

## 七、设置（Settings）

### 7.1 `GET /api/settings`

获取全部设置；缺失项自动填充默认值。

**响应**：

```json
{
  "importance_levels": [
    { "value": 0, "label": "暂存" },
    { "value": 1, "label": "一般" },
    { "value": 2, "label": "..." },
    { "value": 3, "label": "重要" },
    { "value": 4, "label": "关键" }
  ],
  "ai_enabled": true,
  "ai_features": {
    "socratic": true,
    "connector": true,
    "catalyst": true,
    "retro": true,
    "mirror": true,
    "devil": true,
    "coroner": true,
    "translate": true,
    "analyzer": true,
    "blindspot": true
  }
}
```

### 7.2 `PUT /api/settings`

部分更新设置（只更新传入字段）。

**请求体**（字段均可选）：

```json
{
  "importance_levels": [
    { "value": 0, "label": "..." },
    { "value": 1, "label": "..." },
    { "value": 2, "label": "..." },
    { "value": 3, "label": "..." },
    { "value": 4, "label": "..." }
  ],
  "ai_enabled": true,
  "ai_features": { "socratic": false }
}
```

**约束**：

- `importance_levels` 必须为长度 5 的数组，每项含 `value`（数字）与 `label`（非空）
- `ai_features` 部分更新，缺失的开关保持原值

**响应**：`{ "success": true }`。

**错误**：`400 等级数据格式错误`。


## 八、AI 思考伙伴路由

> 所有 AI 路由共享以下约定：
>
> 1. **入参校验**：`idea_id`（可选）/ `title`（必填）/ `content` 等基本字段。
> 2. **失败兜底**：AI 调用失败时返回 `{ "error": "AI unavailable" }` 或 `{ "feature": null, "message": "..." }`，**不抛 5xx**（除非代码 bug）。
> 3. **日志记录**：成功路径会 best-effort 写入 `ai_interactions`（失败不影响主流程）。
> 4. **串行队列**：所有 AI 调用经 `packages/@spark/ai` 进程内串行队列，429/5xx/网络错误自动重试 ≤2 次。

### 8.1 `POST /api/ai/mirror` — 镜子

输入想法画像统计，返回风格标签与解读。

**请求体**：`{ idea_id?, content }`

**响应**：`{ profile: { styleTags: [...], insight: "..." } | null, message? }`

### 8.2 `POST /api/ai/socratic` — 苏格拉底

对一个想法做连续追问。

**请求体**：`{ idea_id, title, content }`

**响应**：`{ questions: ["...", "..."] }`

### 8.3 `POST /api/ai/catalyst` — 杂交催化剂

基于一个想法，AI 推荐可与之杂交的"配偶"。

**请求体**：`{ idea_id, title, content }`

**响应**：`{ partners: [{ idea_id, reason }] }`

### 8.4 `POST /api/ai/connect` — 连接器

扫描非归档/休眠的最近 50 条想法，推荐隐藏连接。

**请求体**：`{}`（无参）

**响应**：

```json
{
  "pairs": [
    { "sourceId": "uuid", "targetId": "uuid", "explanation": "..." }
  ],
  "message": "想法还不够多..." // 当想法 < 5 条时
}
```

### 8.5 `POST /api/ai/coroner` — 验尸官

对一个归档/休眠想法做"死亡原因"分析。

**请求体**：`{ idea_id, title, content, epitaph? }`

**响应**：`{ analysis: { causes: [...], lessons: [...] } }`

### 8.6 `POST /api/ai/devil` — 辩手

对一个想法做反向论证。

**请求体**：`{ idea_id, title, content }`

**响应**：`{ counter: { arguments: [...], weakPoints: [...] } }`

### 8.7 `POST /api/ai/blindspot` — 盲点

识别一个想法的盲点。

**请求体**：`{ idea_id, title, content }`

**响应**：`{ blindspots: [{ aspect: "...", suggestion: "..." }] }`

### 8.8 `POST /api/ai/translate` — 翻译

把想法翻译成另一种表达（更清晰/更简洁/更煽动）。

**请求体**：`{ idea_id, title, content, style: "concise" | "vivid" | "formal" }`

**响应**：`{ variants: [{ style, text }] }`

### 8.9 `POST /api/ai/retro` — 回望对话

生成某时间窗口的回望总结。

**请求体**：`{ window: "day" | "week" }`

**响应**：`{ summary: "...", highlights: [...] }`

### 8.10 `POST /api/ai/analyze` — 全方位分析

对一个想法做五维度分析，**只生成不入库**。

**请求体**：

```json
{
  "idea_id": "uuid（可选）",
  "title": "string（必填）",
  "content": "string",
  "status": "seed",
  "importance_label": "暂存",
  "created_at": "2026-08-21T..."
}
```

**响应**：

```json
{
  "analysis": {
    "dimensions": [
      { "name": "可行性", "content": "..." },
      { "name": "价值", "content": "..." },
      { "name": "风险", "content": "..." },
      { "name": "行动建议", "content": "..." },
      { "name": "待澄清", "content": "..." }
    ],
    "model": "deepseek-v4-flash"
  }
}
```

### 8.11 `POST /api/ai/profile` — 思考风格画像

基于全量想法统计生成个人思考画像。

**约束**：想法数 ≥ 20 且最早想法 ≥ 30 天，否则返回 `{ profile: null, message: "..." }`。

**响应**：`{ profile: { styleTags: [...], insight: "...", stats: {...} } | null, message? }`

### 8.12 `GET /api/ai/interactions` — AI 交互日志（隐私控制）

**Query 参数**：`limit`（1-100，默认 50）

**响应**：

```json
{
  "interactions": [
    {
      "id": "uuid",
      "feature": "socratic",
      "idea_id": "uuid | null",
      "request_summary": "...",
      "response_summary": "...",
      "tokens_used": 1234,
      "created_at": "..."
    }
  ]
}
```
